# Алгоритмы и структуры данных

Репозиторий с решениями задач по алгоритмам и структурам данных, выполненных в рамках обучения в Университете ИТМО.

## 📚 Содержание

В репозитории собраны решения задач по следующим темам:

- **Массивы и строки** — обработка данных, работа с последовательностями.
- **Сортировки и поиск** — сортировка слиянием, бинарный поиск, порядковые статистики.
- **Стеки, очереди и деки** — реализация базовых структур данных.
- **Рекурсия и перебор** — рекурсивные алгоритмы, поиск с возвратом.
- **Кучи** — очереди с приоритетом, потоковая медиана.
- **Жадные алгоритмы** — поиск оптимальных решений.
- **Деревья поиска** — BST, AVL-деревья, балансировка и повороты.

## 💻 Языки программирования

- **Python** — основной язык для изучения и реализации алгоритмов.

## 🎯 Цели репозитория

- Закрепление теоретических знаний на практике.
- Развитие навыков алгоритмического мышления.
- Изучение структур данных и способов их реализации.
- Анализ временной сложности и использования памяти.
- Подготовка к техническим собеседованиям и соревнованиям по программированию.

## 📁 Структура репозитория

Решения распределены по тематическим директориям. Каждый файл содержит реализацию отдельной задачи.

## 🚀 Развитие проекта

Репозиторий пополняется новыми решениями по мере изучения алгоритмов и структур данных.
